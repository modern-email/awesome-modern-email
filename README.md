## Standards

Most email standardization is ongoing in IETF working groups, each having a dedicated mailing list. It's free to join!

Currently active email-related WGs involve:
- [Mail Maintenance (mailmaint)](https://datatracker.ietf.org/wg/mailmaint/about/)
- [JSON Mail Access Protocol (jmap)](https://datatracker.ietf.org/group/jmap/about/) (see also [JMAP.io](https://jmap.io/))
- [Structured Email (sml)](https://datatracker.ietf.org/group/sml/about/) (see also [Structured.email](https://structured.email/))
- [Domain Keys Identified Mail (dkim)](https://datatracker.ietf.org/wg/dkim/about/)
- [Open Specification for Pretty Good Privacy (openpgp)](https://datatracker.ietf.org/wg/openpgp/)
- [Limited Additional Mechanisms for PKIX and SMIME (lamps)](https://datatracker.ietf.org/wg/lamps/about/)

Note that various prior WGs still run mailing lists with certain traffic.
